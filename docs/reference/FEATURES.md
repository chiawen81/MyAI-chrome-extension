## 功能一：網頁雙語翻譯

**觸發**：popup「翻譯此頁」按鈕或快捷鍵 Alt+T。background 動態注入 content script（activeTab + scripting），再次觸發即還原原文（移除所有 `data-bt-translation` 節點與注入的 `<style>`）。

**實際行為**：
- 掃描 `p, h1~h6, li, blockquote, dd, dt, figcaption, td, th`；排除 `pre/code/textarea/input/select/contenteditable` 內的文字、巢狀外層（li 裡有 p 只翻最內層）、無文字或隱藏元素。
- 惰性翻譯：IntersectionObserver（rootMargin 預抓「上方 0.5、下方 2 個螢幕高」，讓捲動時段落多半已翻好）；MutationObserver 追蹤動態內容（變動合併 1 秒再重掃）。
- 段落進入預抓範圍後先顯示「翻譯中…」佔位，400ms 收集窗口收齊後切成小組（≤8 段／≤1200 字元）**各自**送 background，回應到達即渲染該組譯文（漸進出現，不等整批）；並發受設定的並發數（預設 3）限制。background 另有 3000 字元／30 段的子批次上限作為防呆（主要供 YouTube 整批翻譯使用）。
- background 注入 content script 後會輪詢 PING 等待就緒（100ms × 最多 20 次）再轉發翻譯指令，第一次按「翻譯此頁」即可啟動。
- 譯文作為原文元素的**子節點**附加在最後，CSS `display:block` 呈現在原文下方；不修改原文任何節點。
- 單頁字數上限（預設 10,000 字元）達到後停止翻譯並顯示 toast，一次為限。
- 翻譯失敗：移除佔位節點、錯誤訊息放到元素 `title`、右下角 toast 提示。

**已知限制**：
- 譯文是純文字（`textContent`），原文段落內的連結、粗體等行內格式不會保留在譯文中。
- `chrome://`、Chrome Web Store 等頁面無法注入，popup 會顯示「此頁面無法翻譯」（原因放按鈕 tooltip，2 秒後恢復按鈕可重試）。
- 翻譯狀態存在頁面記憶體中，重新整理頁面後回到未翻譯狀態（快取仍在，重翻不重新扣費）。
- 與沉浸式翻譯等其他翻譯外掛**同時開啟**時，對方插入的譯文節點沒有 `data-bt-translation` 標記，本外掛重掃時會把它們也送去翻譯（浪費 token）；測試與日常使用建議擇一啟用。

## 功能二：YouTube 雙語字幕

**觸發**：watch 頁播放器工具列的機器人圖示按鈕 → 面板選來源字幕軌 → 開啟雙語字幕。

**實際行為**：
- 播放器按鈕使用 `currentColor` 圓角線性機器人 SVG，固定 48px 按鈕容器與 28px 圖示並以 flex 置中，避免 YouTube 對 SVG 套用 padding 時溢位；hover 提升亮度、字幕準備中顯示呼吸動畫、啟用時顯示紅色狀態線，並同步維護 `aria-expanded`、`aria-pressed`、`aria-busy` 與狀態標籤。
- 字幕軌取得（`subtitle-provider.ts`，隔離模組）：同源重新 fetch watch 頁 HTML → 括號配對掃描抽出 `ytInitialPlayerResponse` → 讀 `captionTracks`。
- 字幕內容取得（2026-07-13 修復 #18）：依序嘗試 `fmt=json3` → `fmt=srv3` → 預設 XML（baseUrl 帶 `variant` 參數時另以去除 variant 的 URL 重試一輪）；全部回空時走 InnerTube 備援（`youtubei/v1/player`，ANDROID client）重新取得**不需 pot token** 的 baseUrl 再試一輪——YouTube 對 timedtext 要求 pot、缺了會回 200 空 body 而非 4xx，watch 頁 HTML 內的 baseUrl 無 pot。失敗時錯誤有分類：空內容（「字幕來源回傳空內容…」）／非預期內容／格式解析失敗（「可能已改版」）。
- 面板預設選第一條人工字幕（沒有才選自動產生）。
- 整批預翻譯（2026-07-14 優化 #20）：首批固定 10 句並單獨先送，完成渲染後其餘字幕依批次大小（預設 40 句，下限 5）進入並發池；並發上限沿用共用設定（預設 3）。每批附前一批最後 2 句原文作 context，回應到達即依原索引漸進補上譯文；進度依實際完成句數累加。任一批失敗即停止派發新批、保留已完成譯文，且不寫入影片級整包快取。
- 字幕呈現：自繪 overlay（原文白色在上、譯文在下），隱藏原生字幕；`timeupdate`/`seeking` + 二分搜尋切換當前句；字級隨播放器高度縮放（全螢幕自動變大），樣式沿用功能一的設定並即時反映。
- 快取以整部影片為單位（key 含影片 ID、供應商、模型、專家、目標語言、字幕軌語言、是否自動產生），命中時直接載入不扣費。
- 換片偵測：`yt-navigate-finish` 事件 + 每秒輪詢 URL 雙保險；換片即銷毀 overlay、取消進行中的翻譯（cancelled 旗標 + runToken 檢查點），並於新 session 建立後重置面板（面板開著時自動載入新影片的字幕軌清單，2026-07-14 修復 #19）；離開 watch 頁則直接收合面板。

**已知限制**：
- `subtitle-provider.ts` 依賴 YouTube 未公開的頁面結構，改版即失效（錯誤訊息會註明「YouTube 可能已改版」）；修補範圍已隔離在該檔案。InnerTube 備援（ANDROID client）屬 yt-dlp 式的軍備競賽路徑，失效週期不可控，重修時先跑計畫附錄的最小重現（`plans/archive/2026-07-13-修復-YouTube字幕空回應誤判為格式錯誤.md`）。
- 整批預翻譯不跟隨播放位置：即使影片暫停或只觀看前段，仍會把整部字幕翻完，可能浪費未觀看區段的 token；播放點若已超過首批範圍，也可能在首批完成後仍暫時只看到原文。動態視窗翻譯列看板 #21。
- 整批預翻譯完成前關閉字幕再重開，會從快取／重新翻譯開始，不接續先前進度（單段快取使 API 費用不重複）。
- 部分翻譯後換片，未完成的譯文不寫入整部影片快取（但逐句快取仍有效）。
- 字幕重疊的軌道（同一時間多句）只顯示二分搜尋命中的一句。

## 功能三：右鍵選單 Claude 助手

**觸發**：http/https 頁面右鍵 → 外掛子選單五個動作——「請 Claude 摘要此頁」（空白處與選取時皆顯示）、「請 Claude 摘要選取文字」「將選取文字帶入 Claude」「請 Claude 翻譯」「請 Claude 翻譯＋摘要」（僅選取時顯示）。

**實際行為**：
- **交棒模式**：外掛不呼叫 API、不扣費——開新分頁 `claude.ai/new`，注入 script 把「指示句＋內容」寫進輸入框（`execCommand('insertText')`，換行保留），除「帶入選取文字」外自動送出（填入後輪詢送出鈕出現再點擊）。「帶入選取文字」只填不送、結尾「我的問題：」，讓使用者接著輸入問題一次送出。
- **摘要此頁**：以 `executeScript({ func })` 在原分頁擷取主內容（語意容器 article/main/[role=main] 內收段落區塊＋排除 nav/footer/aside 等雜訊 → 啟發式共同祖先 → `body.innerText` 回退），連同標題、網址帶入；摘要語言跟隨目標語言設定。
- **摘要選取文字**：以目標語言摘要選取段落。「翻譯」「翻譯＋摘要」固定輸出正體中文（預設模板）。
- **中文確認**：翻譯類動作選到漢字占比 ≥ 50% 的內容時，原頁跳 confirm 確認，取消即中止（confirm 注入失敗視同確認，fail-open）。
- **超長截斷**：帶入內容超過 `assistantMaxChars`（預設 50,000、下限 500，options「Claude 助手」分頁可調）→ 保留開頭截斷＋文末「（內容過長，已截斷）」註記。
- **模板自訂**：options「Claude 助手」分頁每個動作一個 textarea（必含 `{{content}}`、≤ 500 字元，違規 alert 擋下不寫入；清空即還原預設；可用變數另有 `{{page_url}}`、`{{page_title}}`、`{{target_lang_label}}`）；自動送出與否不開放調整。
- **交棒模型（依動作各選）**：每張動作模板卡有「交棒模型」下拉（Haiku 4.5／Sonnet 5／Opus 4.8／Fable 5；預設「跟隨 claude.ai 目前選擇」）——有指定時開分頁網址帶 `?model=<slug>`（該對話即用該模型），未指定則網址不帶參數、行為同以往；`?q=` 備援網址也同步帶上 `model` 參數。模型清單寫死於 `ASSISTANT_MODELS` 常數（`shared/assistant-prompts.ts`），不開放自由輸入（無效 slug 會原樣顯示在 claude.ai 模型按鈕上）。
- **備援**：注入失敗或找不到輸入框（逾時 15 秒）→ 同分頁改導向 `claude.ai/new?q=`（截斷至 2,000 字元備援上限）；輸入框可填但送出鈕失效 → 保留已填文字不送出（使用者自行按 Enter）。

**已知限制**：
- 依賴 claude.ai 未公開 DOM 結構（輸入框／送出鈕選擇器），改版即失效；依隔離慣例集中於 `content/claude-inject/`，並有 `?q=` 備援。
- **需先登入 claude.ai**：未登入時會被導向登入頁，帶入內容不保留（不做重試機制）。
- 程式化操作 claude.ai 頁面未經 Anthropic 官方支持（ToS 灰色地帶；本機自用風險低，上架前需自行評估）。
- 選取文字經 `info.selectionText` 取得，會被 Chrome 壓成單行、極長選取可能截斷。
- **待觀察**：「摘要此頁」的擷取對特殊版型仍可能帶入較多非本文文字（預設模板已提醒 AI 自行忽略雜訊，2026-07-11 新聞網站實測可接受）；遇干擾暴增的版型再另開優化任務。
- 備援 `?q=` 路徑的內容會短暫出現在網址（瀏覽歷史）；claude.ai 對 URL 預填內容會顯示警告橫幅（其防護措施，不影響功能）。
- `?model=` 屬 claude.ai 未公開行為，改版可能失效——失效時參數被忽略、交棒照常進行（優雅降級，用當下預設模型，無錯誤）；模型換代時更新 `ASSISTANT_MODELS` 常數即可（重驗步驟見計畫附錄）。
- **交棒模型會影響後續新對話的預設**（2026-07-11 驗收實測）：claude.ai 以「上次使用的模型」作為新對話預設，交棒送出後使用者手動開的新對話可能預設為交棒所選模型——此為 claude.ai 自身行為，非本外掛可控。（spike 當日僅驗證「開 `?model=` 分頁不改預設」，未覆蓋送出後的記憶行為。）

## 共用基礎

- **AI 專家**：內建 4 種（通用／技術文件／學術論文／新聞）＋自訂（options 頁新增／編輯／刪除）；刪除使用中的自訂專家會自動退回「通用」。
- **樣式**：5 種預設集（無樣式／虛線底線／馬克筆／引用／粗體）＋進階自訂（文字色、背景色、字級 %、字型）；字型欄位提供常用選項（`<datalist>`，8 種中英文常見字型）並保留自訂輸入；文字色／背景色文字欄位旁附色盤（`<input type="color">`），與文字欄位雙向同步（色盤選色會回填 hex 到文字欄位並存檔；文字欄位手動輸入合法 CSS 顏色如具名色會同步色盤色塊、但不覆寫文字欄位原值，無法解析時色盤維持原狀）；options 頁有即時預覽（與 content script 共用同一套 CSS 產生邏輯）。
- **批次翻譯協定**：JSON 陣列進出，要求等長同序；解析失敗或長度不符 → 自動逐段重試 fallback。
- **快取**：`hash(原文+供應商+模型+專家+目標語言)`，options 進階分頁可看筆數與清除。
- **測試連線**：options 頁以表單當下值（未儲存）直接測試，回報成功或 API 錯誤訊息。
- **設定**：所有欄位改了即存（無儲存鈕）；popup 可快速切換目標語言／供應商／專家。
