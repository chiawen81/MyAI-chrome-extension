## 功能一：網頁雙語翻譯

**觸發**：popup「翻譯此頁」按鈕或快捷鍵 Alt+T。background 動態注入 content script（activeTab + scripting），再次觸發即還原原文（移除所有 `data-bt-translation` 節點與注入的 `<style>`）。

**實際行為**：
- 掃描 `p, h1~h6, li, blockquote, dd, dt, figcaption, td, th`；排除 `pre/code/textarea/input/select/contenteditable` 內的文字、巢狀外層（li 裡有 p 只翻最內層）、無文字或隱藏元素。
- 惰性翻譯：IntersectionObserver（rootMargin 下方 200px 預抓）；MutationObserver 追蹤動態內容（變動合併 1 秒再重掃）。
- 段落進入視口後先顯示「翻譯中…」佔位，400ms 收集窗口合併成一批送 background；background 再按 3000 字元／30 段上限切子批次，受並發數（預設 3）限制。
- 譯文作為原文元素的**子節點**附加在最後，CSS `display:block` 呈現在原文下方；不修改原文任何節點。
- 單頁字數上限（預設 10,000 字元）達到後停止翻譯並顯示 toast，一次為限。
- 翻譯失敗：移除佔位節點、錯誤訊息放到元素 `title`、右下角 toast 提示。

**已知限制**：
- 譯文是純文字（`textContent`），原文段落內的連結、粗體等行內格式不會保留在譯文中。
- `chrome://`、Chrome Web Store 等頁面無法注入，popup 會顯示「此頁面無法翻譯」。
- 翻譯狀態存在頁面記憶體中，重新整理頁面後回到未翻譯狀態（快取仍在，重翻不重新扣費）。

## 功能二：YouTube 雙語字幕

**觸發**：watch 頁播放器工具列的「譯」按鈕 → 面板選來源字幕軌 → 開啟雙語字幕。

**實際行為**：
- 字幕軌取得（`subtitle-provider.ts`，隔離模組）：同源重新 fetch watch 頁 HTML → 括號配對掃描抽出 `ytInitialPlayerResponse` → 讀 `captionTracks`；字幕內容優先 json3 格式，失敗退回 XML timedtext。
- 面板預設選第一條人工字幕（沒有才選自動產生）。
- 整批預翻譯：依批次大小（預設 40 句，下限 5）循序送翻，每批附前一批最後 2 句原文作 context；進度條逐批更新，字幕層譯文漸進補上（未翻到的句子只顯示原文）。
- 字幕呈現：自繪 overlay（原文白色在上、譯文在下），隱藏原生字幕；`timeupdate`/`seeking` + 二分搜尋切換當前句；字級隨播放器高度縮放（全螢幕自動變大），樣式沿用功能一的設定並即時反映。
- 快取以整部影片為單位（key 含影片 ID、供應商、模型、專家、目標語言、字幕軌語言、是否自動產生），命中時直接載入不扣費。
- 換片偵測：`yt-navigate-finish` 事件 + 每秒輪詢 URL 雙保險；換片即銷毀 overlay、取消進行中的翻譯（cancelled 旗標 + runToken 檢查點）、重置面板。

**已知限制**：
- `subtitle-provider.ts` 依賴 YouTube 未公開的頁面結構，改版即失效（錯誤訊息會註明「YouTube 可能已改版」）；修補範圍已隔離在該檔案。
- 整批預翻譯完成前關閉字幕再重開，會從快取／重新翻譯開始，不接續先前進度（單段快取使 API 費用不重複）。
- 部分翻譯後換片，未完成的譯文不寫入整部影片快取（但逐句快取仍有效）。
- 字幕重疊的軌道（同一時間多句）只顯示二分搜尋命中的一句。

## 共用基礎

- **AI 專家**：內建 4 種（通用／技術文件／學術論文／新聞）＋自訂（options 頁新增／編輯／刪除）；刪除使用中的自訂專家會自動退回「通用」。
- **樣式**：4 種預設集（無樣式／虛線底線／馬克筆／引用）＋進階自訂（文字色、背景色、字級 %、字型）；options 頁有即時預覽（與 content script 共用同一套 CSS 產生邏輯）。
- **批次翻譯協定**：JSON 陣列進出，要求等長同序；解析失敗或長度不符 → 自動逐段重試 fallback。
- **快取**：`hash(原文+供應商+模型+專家+目標語言)`，options 進階分頁可看筆數與清除。
- **測試連線**：options 頁以表單當下值（未儲存）直接測試，回報成功或 API 錯誤訊息。
- **設定**：所有欄位改了即存（無儲存鈕）；popup 可快速切換目標語言／供應商／專家。
