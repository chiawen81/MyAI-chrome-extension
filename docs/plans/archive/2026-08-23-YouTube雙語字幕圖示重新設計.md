# YouTube 雙語字幕圖示重新設計

> status: completed（2026-08-30 手動驗收通過）
> 建立日期：2026-08-23

<br><br>

## 🔸 1. User Story

身為在 YouTube 觀看影片的使用者，我想要播放器上的雙語字幕按鈕看起來像原生控制項，並能一眼辨識字幕是否正在載入或已啟用，而不是看到一個突兀的粗體「譯」字。

<br><br>

## 🔸 2. Spec

### 🔹 2.1 視覺設計

- 以 36 × 36 viewBox 的 inline SVG 繪製圓角線性機器人，使用 `currentColor` 跟隨 YouTube 控制列顏色。
- 圖示維持約 24px 視覺尺寸，以圓形天線、圓眼、圓角嘴與獨立耳朵保留參考圖特徵，同時降低實心面積，使視覺重量貼近 YouTube 原生控制圖示。
- hover 提升亮度；載入時柔和呼吸；字幕啟用時在按鈕底部顯示 YouTube 紅色狀態線。

### 🔹 2.2 互動與無障礙

- 保留原本按鈕開關面板的行為。
- 同步維護 `aria-expanded`、`aria-pressed`、`aria-busy` 與可讀的 `aria-label`。
- 換片、啟動失敗或關閉字幕時，按鈕狀態須正確還原。

### 🔹 2.3 驗收標準

- [x] 控制列不再出現「譯」字，圖示在一般與全螢幕模式皆清晰且不變形。
- [x] hover、準備中、字幕已啟用三種狀態可視覺辨識。
- [x] 開關面板與雙語字幕的既有功能不受影響。
- [x] 鍵盤焦點與無障礙屬性能正確反映面板／字幕狀態。
- [x] `npm run build` 成功並產出最新版 `dist/`。
